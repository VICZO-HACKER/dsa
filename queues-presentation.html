What is Queue ADT?

  • A queue is a linear abstract data type that follows the FIFO principle.
  • FIFO = First In, First Out: the element inserted first is removed first.
  • Insertion takes place at the rear end, deletion at the front end.
  • ADT = Abstract Data Type: it defines the operations without specifying how they are implemented internally.
  • A queue can be implemented using an array or a linked list.

Working of Queue ADT

  1. Step 1: Initially, the queue is empty.
  2. Step 2: Enqueue(10), Enqueue(20), Enqueue(30).
  3. Step 3: Dequeue(): 10 is removed because it was inserted first.
  4. Step 4: Result: deleted element = 10, front element = 20.
The first inserted element is the first one removed. Therefore, the queue follows FIFO.

Circular Queue

  • The array is treated as a circle.
  • After reaching the end of the array, insertion wraps around to the beginning to use the available space.
  • This solves the wasted-space limitation of a simple array queue.

Priority Queue

  • Every element has a priority along with its value.
  • The element with the highest priority is removed first, not necessarily the one inserted first.
  • Elements with the same priority are served in FIFO order.

Deque (Double-ended queue)

  • Insertion and deletion are allowed at both ends: front and rear.
  • insertFront() and insertRear() add elements.
  • deleteFront() and deleteRear() remove elements.

Advantages and Limitations

Advantages

  • Maintains the order of elements according to the FIFO principle.
  • Useful for scheduling tasks and managing requests.
  • Efficient insertion and deletion when implemented appropriately.

Limitations

  • A simple fixed-size array queue has limited capacity.
  • An ordinary linear array implementation may waste space after deletions unless managed carefully.
These limitations can be addressed by using circular queues or linked-list-based implementations. Circular queue: after reaching the end of the array, insertion wraps around to the beginning to use the available space.
